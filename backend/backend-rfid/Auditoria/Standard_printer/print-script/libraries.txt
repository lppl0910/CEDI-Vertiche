bwip-js -----------------> es una librería que genera códigos de barras y QRs, buena opción
                          para hacer el diseño inicial del QR.

fs ----------------------> Usado para guardar archivos, importante para el formato de 
                           impresión de más adelante.

canvas ------------------> Una librería que encombinación de bwip, podemos generar el
                           sticker completo con el texto para proveer info visual.

@zxing/library canvas ---> Validación de que se pueda leer el barcode de manera 
                           automática.
